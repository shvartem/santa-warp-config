# WARP Config Builder

**WARP Config Builder** — это простой веб-инструмент для генерации конфигурационного файла **AmneziaWG** (формат `.conf`) из JSON‑ответа, получаемого от API.

Создан для удобного получения готового конфига для Cloudflare WARP, который можно сразу скопировать или сохранить на устройство.

> ⚠️ **По умолчанию нужен клиент с поддержкой AmneziaWG** — например, [AmneziaVPN](https://amnezia.org) или AmneziaWG.
> Конфиг содержит параметры обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`–`H4`, `I1`), которые обычный клиент WireGuard не понимает.
> Для официального приложения WireGuard или роутера выберите формат «Обычный WireGuard» — но он работает только там, где WARP не блокируется.

---

## Возможности

- ⚡ Получение конфига в один клик через свой Worker (ключи создаются в браузере), ручной способ через santa-atmo.ru остаётся запасным
- 🔧 Преобразование JSON в конфигурацию AmneziaWG
- 🔀 Два формата: AmneziaWG (с маскировкой трафика) и обычный WireGuard
- 🌐 Выбор DNS-сервиса (Cloudflare, Google, COMSS, MALW) или свои DNS-серверы
- 🛰️ Выбор endpoint и порта WARP (в т.ч. свой адрес/порт) — если соединение не устанавливается на одном порту, можно попробовать другой
- ⚙️ Дополнительные настройки: какой трафик пускать через WARP (весь, без локальных сетей, только IPv4 или свой список), MTU, PersistentKeepalive
- 📥 JSON можно вставить кнопкой из буфера, загрузить файлом или перетащить файл в поле — конфиг соберётся сразу
- 📋 Копирование результата в буфер обмена
- 💾 Сохранение в файл
- 📱 QR-код для импорта в мобильное приложение (генерируется в браузере, конфиг никуда не отправляется)
- 🌙 Светлая и тёмная тема (по умолчанию — как в системе)

## Как использовать

1. Откройте [страницу инструмента](https://shvartem.github.io/santa-warp-config/) или запустите локально.
2. Нажмите **«⚡ Получить конфиг автоматически»** — конфиг соберётся сам.
   Если кнопки нет или она не сработала, получите JSON вручную:
   - перейдите по ссылке [https://santa-atmo.ru/warp/warp.php](https://santa-atmo.ru/warp/warp.php) (откроется в новой вкладке) и скопируйте содержимое;
   - вставьте JSON в текстовое поле на странице (или кнопкой «Вставить из буфера») — конфиг соберётся сам; если нет, нажмите **«Собрать конфиг»**.
3. После успешной генерации вы сможете:
   - скопировать конфиг в буфер обмена;
   - сохранить его как файл `warp_santa_<dns>.conf`;
   - показать QR-код и отсканировать его в приложении AmneziaWG (или сохранить QR как PNG).

## Установка и запуск

Проект не требует сборки или установки зависимостей.

### Локальный запуск
Страница загружает общий шаблон `template.conf`, поэтому при открытии файла напрямую (`file://`) браузер его не отдаст. Запустите любой локальный веб-сервер:

```bash
git clone https://github.com/shvartem/santa-warp-config.git
cd santa-warp-config
python3 -m http.server 8000
```

и откройте <http://localhost:8000>.

### Скрипт для терминала
`generate_warp_santa.sh` сам регистрирует аккаунт WARP и сохраняет готовый конфиг — переходить по ссылке и копировать JSON не нужно.

По умолчанию скрипт регистрируется **напрямую у Cloudflare**: пара ключей создаётся на вашем компьютере (через `wg`, `openssl` или `python3` — что найдётся), Cloudflare получает только публичный ключ, и приватный ключ никуда не уходит. Если прямая регистрация не удалась, скрипт берёт конфиг у santa-atmo.ru — в этом случае приватный ключ создаёт их сервер. Выбрать источник явно можно параметром `--source`. Умеет всё то же, что страница: формат, DNS, endpoint, AllowedIPs, MTU, keepalive. Нужны `curl` и `jq`; работает и со старым bash 3.2 (macOS).

```bash
bash generate_warp_santa.sh                       # спросит имя файла (Enter — warp_santa_cloudflare.conf)
bash generate_warp_santa.sh --dns google --port 2408 -o home.conf
bash generate_warp_santa.sh -f wg -a nolan -o router.conf
bash generate_warp_santa.sh --json response.json -o - > warp.conf
bash generate_warp_santa.sh --help                # все параметры
```

| Параметр | Значения | По умолчанию |
|---|---|---|
| `-s`, `--source` | `auto` — Cloudflare, при ошибке santa; `cloudflare` — только напрямую; `santa` — только через santa-atmo.ru | `auto` |
| `-f`, `--format` | `awg` — AmneziaWG, `wg` — обычный WireGuard | `awg` |
| `-d`, `--dns` | `cloudflare`, `google`, `comss`, `malw` или свои адреса через запятую | `cloudflare` |
| `-e`, `--endpoint` | `HOST:PORT`, IPv6 — `[адрес]:PORT` | `162.159.192.1:500` |
| `-p`, `--port` | только порт: `500`, `2408`, `1701`, `4500` или свой | `500` |
| `-a`, `--allowed-ips` | `all`, `nolan` (кроме локальных сетей), `ipv4` или свой список подсетей | `all` |
| `--mtu` | 1280–1500 | `1280` |
| `--keepalive` | 0–65535 секунд, `0` — выключить | `25` |
| `-o`, `--out` | имя файла или `-` (вывести в консоль) | `warp_santa_<dns>.conf` |
| `-j`, `--json` | готовый ответ santa из файла или `-` (stdin) вместо регистрации | — |
| `--force` | перезаписать существующий файл без вопроса | — |

Существующий файл скрипт без `--force` не перезапишет: в терминале спросит, в скриптах и по расписанию — завершится с ошибкой. Файл создаётся с правами `600`, потому что в нём приватный ключ.

## Структура

- `index.html` — веб-страница
- `generate_warp_santa.sh` — скрипт для терминала
- `vendor/qrcode-generator-1.4.4.js` — генератор QR-кодов ([kazuhikoarase/qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator), MIT), лежит в репозитории, чтобы страница не зависела от CDN
- `worker/` — прокси регистрации на Cloudflare Workers для кнопки автоматического получения конфига; инструкция по развёртыванию — в [worker/README.md](worker/README.md)
- `template.conf` — общий шаблон конфига для страницы и скрипта. Параметры AmneziaWG, endpoint и т.п. меняются только здесь.
